Review Desk Helper

Connects this extension to your Review Desk so it can offer approved replies on the Yelp Reviews page. The token stays in Chrome's extension storage and is never exposed to the Yelp page itself.

Where your Review Desk is deployed. Not hosted on Render? Add your host to host_permissions in manifest.json.
Same value as DASHBOARD_TOKEN on the server.
Tags reviews this extension re-ingests. Only useful if one Review Desk serves several listings; leave blank otherwise.
